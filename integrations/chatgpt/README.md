# Side Badger ChatGPT plugin package

This directory contains the submission package source: `plugin.json`, `mcp.json`
and `assets/icon.png`. The packager in the shared bill-splitter repository adds the
shared `manage-shared-expenses` skill when it builds the ZIP. Upload that ZIP
through **With MCP**; there is no `.app.json` and no app ID.

See [ChatGPT plugin delivery](../../docs/chatgpt-plugin.md) for package contents,
how to build the ZIP, production URLs, verification evidence and the remaining
submission steps.
